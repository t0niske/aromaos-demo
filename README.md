# AromaOS — демо

**Открыть: https://t0niske.github.io/aromaos-demo/**

Демо-версия AromaOS — системы управления бизнесом аромамаркетинга в Астане: лиды и канбан продаж, клиенты, объекты с зонами и ароматами, подписки и продления, визиты техника, оборудование с QR-наклейками, задачи и настройки.

![Дашборд](https://raw.githubusercontent.com/t0niske/aromaos/main/docs/screenshots/dashboard.webp)

- **Без входа и без сервера.** Это та же система, что в [t0niske/aromaos](https://github.com/t0niske/aromaos), но целиком в браузере: база PostgreSQL (PGlite) работает прямо на странице.
- **Можно всё менять.** Двигать лиды по этапам, оформлять подписки, отмечать визиты и задачи. Изменения видите только вы, после перезагрузки страницы данные снова исходные.
- **Разные роли.** Сначала открывается под собственником. В плашке «Демо» внизу справа можно посмотреть глазами менеджера продаж, руководителя сервиса или техника. Сразу под ролью: [менеджер](https://t0niske.github.io/aromaos-demo/#/login?as=sales) · [сервис](https://t0niske.github.io/aromaos-demo/#/login?as=service) · [техник](https://t0niske.github.io/aromaos-demo/#/login?as=tech).
- Компании и люди вымышленные, цены — из прайса Nova 300 / Nova 1000.

В этом репозитории только собранный сайт для GitHub Pages. Исходный код и описание сборки — в [t0niske/aromaos](https://github.com/t0niske/aromaos#браузерная-демо-версия) (`npm run demo:build`).
